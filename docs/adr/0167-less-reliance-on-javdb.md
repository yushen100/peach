# ADR-0167：少找 JavDB：有替代就绕过，作品资料取到就留作本地资料

- 状态：已采纳
- 日期：2026-11-16
- 关系：修订 [ADR-0144](0144-javdb-scraping-uses-the-anonymous-api.md)「发行满一个月的作品不再重取」的快照保留期；沿用 [ADR-0166](0166-javdb-background-reads-are-anonymous.md) 的匿名后台取页与账号停用识别

## 背景

ADR-0166 之后后台取页不再带账号，但 JavDB 仍是订阅、想要定时查找、磁链查找与新作资料的共同上游，取页总量没有变少。
JavDB 独有的是评论区和素人、无码作品的资料；有码作品的片单、资料与磁链都另有来源：女优片单有 DMM，磁链有 manko、sukebei 与 JavBus。
作品快照原先发行满一个月才固定，新作在这之前每天重取一次；新作资料边车最多存 2048 条，超出就丢最早的，丢掉的下次再取。

用户的要求是不停用 JavDB，但有替代时绕过它；新作取到的资料直接当本地资料，不按天数过期。

## 决策

**一、订阅：DMM 片单答得上的女优，跳过她的 JavDB 有码页。** 同一实体有启用中的 DMM 女优订阅、最近一次抓取成功时，
她的 JavDB 女优订阅不进到期队列；JavDB 页被标为无码的照抓。订阅本身不停用，DMM 那条出错就回到照常抓取。

**二、想要定时查找：manko 已有 1080p 以上时跳过 JavDB。** 定时查找走快速模式，manko 先给出 1080p／2160p 就不问 JavDB，
sukebei 与 JavBus 照查；手动查找资源不受影响。

**三、磁链加 JavBus。** 读作品页的 `gid`／`img`／`uc`，再取站内磁链表；页面番号对不上就当站上没有。
「字幕」标签记中文字幕；「高清」不等于 1080p，只作属性保留。各来源合并时按 infohash 去重。

**四、作品资料取到就固定。** 公开快照分三种保留：

| 快照 | 保留 |
| --- | --- |
| 番号认出的作品 id | 取到就固定 |
| 作品资料，标题、发行日、封面齐全，发行日当天或之后取得 | 固定，当本地资料 |
| 同上，发行前取得 | 留到发行日，当天起补取一次 |
| 资料不全、磁链、评论、图片 | 照旧按发行日期规则过期 |

磁链链刷新时只重取磁链与评论，作品资料按上表复用。新作资料边车按同一张表判断，不再限制条数，只在文件超过 64 MB 时丢最早的记录。

## 理由

- 绕过而不停用：替代来源出错时 JavDB 仍能顶上，用户不需要手动切换。
- 作品资料发行后基本不变；发行前常缺演员、封面会换，发行日补取一次就够。
- 磁链和评论会陆续增加，固定会错过新资源。

## 后果

- JavDB 上发行后才改的资料（改标题、补演员）不会自动更新；用户在库外详情点刷新仍会重取。
- 已有的快照没有固定标记，下次过期重取后按新规则固定。
- 女优的 DMM 片单漏收的作品（例如只在 JavDB 收录的合集）不再从 JavDB 订阅补上。
