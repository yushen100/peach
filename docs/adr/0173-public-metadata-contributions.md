# ADR-0173：公共资料贡献经独立同意与复核后进入种子

- 状态：已采纳
- 日期：2026-11-18
- 关联：issue #768；ADR-0052、ADR-0106、ADR-0117、ADR-0122、ADR-0157

## 背景

现有实体种子由维护者显式更新，口味研究只投影馆藏和偏好，不保存逐字段纠错及证据。用户要求收集可复用的公开元信息，减少重复刮削；中文化范围仅为女优姓名。

## 决策

公共资料贡献使用独立、默认关闭的同意记录。开启前生成本机完整预览并明确同意用途，上传格式与同意范围首版均为 1。现有诊断与口味研究开关、实例标识和授权不变。新用途不从既有授权推导。

贡献投影只读取已有作品公开字段、字段归属、人物来源编号及采集事实、受控标签、标签映射、封面公开引用、绑定图片摘要的手动裁切、明确未收录与最近来源检查。资料站错误、超时、限流和未收录分别保存；没有耗时就保持缺失，不估算。不会采集影片、图片字节、文件名、路径、凭据、评分与观看记录，也不为贡献重新联网或遍历媒体。不能安全投影的值计入省略数，整份快照超限时不发送截断片段。

女优中文名使用主动贡献入口，记录可核对的公开人物编号、来源已有的原文艺名、中文名与语言。用户可附上公开参考链接，公开种子仍须由维护者给出复核引用。统称选择、自定义昵称和任意人工别名不会自动构成公共译名贡献。提交只产生本机待共享候选，仍需公共资料贡献的独立授权才会发送。

传输复用现有独立研究接收项目、紧凑 JSON、标准库 gzip、Sentry SDK 及最终传输门槛。每 UTC 自然周最多一次实际发送，重新启用不重置次数。最终发送前核对授权代际，失败和未知不在当周重复发送；准备失败可以重新准备。HTTP 接受、附件留存、人工复核和公共种子采纳是不同状态。

维护者下载附件后导入私有 SQLite 归档。每安装每周保留最新接收的一份，汇总只取各安装最新周；同一安装的重复值不重复计数。相同字段和值合并支持统计，同时保留来源域、人工提交数量、冲突及原始私有附件。安装数不等于人数，来源域数也不保证证据独立。没有按票数自动批准的入口。

维护者逐项给出引用和理由后，才可导出 `resources/seed/metadata.json`。公共包不携带贡献实例与私有支持统计，修订递增并保留显式撤销。移除某项不等同于证明它错误；精确撤销必须指明已发布断言。运行资源通过现有统一打包清单分发，不新增远端更新器或依赖。

女优名显示仍是只读投影，须有公开编号命中、无本机身份冲突、原文艺名一致；个人统称、原始别名及作品署名不因此改写。作品资料通过既有候选、字段归属和来源策略落地，公共包不冒充发行商。足够的必填资料可短路外部查询，显式重采绕过公共包。标签映射保留本机决定优先；裁切仅对图片摘要和尺寸均相同的封面复用，保留本机手动裁切。

撤销立即停止对应包项的后续使用，旧修订的公共作品候选不再参与结算。已经写入的账本字段和个人修改不会被读取投影删除；需要撤回已落库批次时沿用既有复核与撤回入口。

## 验收

临时数据回归覆盖默认关闭、独立授权、预览过期、关闭后的传输门槛、跨进程周限次、传输回执、私有值拒收、重复安装与跨周去重、冲突、逐项证据要求、撤销、同名不同身份、人工名称保护、旧候选失效、缺字段继续刮削和图片指纹不匹配。
