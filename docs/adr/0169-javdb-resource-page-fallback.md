# ADR-0169 JavDB 资源接口要求登录时读取作品页

- 状态已采纳
- 日期为 2026-11-17
- 修订 [ADR-0160](0160-javdb-scraping-falls-back-to-detail-pages.md) 的资源接口假设，沿用 [ADR-0166](0166-javdb-background-reads-are-anonymous.md) 的账号使用范围与 [ADR-0168](0168-no-single-source-for-outside-works.md) 的多来源资源查询

## 背景

公开磁链接口在 HTTP 200 响应中返回 `JWTVerificationError`。同一作品的网页可以正常读取，并明确区分已有磁链和暂无分享。原实现只为搜索和作品资料提供网页后备，因此将磁链查询记成来源失败。

## 决策

磁链接口要求登录且调用方提供网页读取器时，核对作品页番号后读取磁链区与有界评论。复用历史资源解析、现有传输、请求预算、主机间隔与来源冷却，同一轮复用已读取的页面。

用户打开的想要资源面板加入已有账号请求清单。后台任务继续按 ADR-0166 处理。网页明确表示暂无磁链时返回正常空结果。来源拒绝、结构无法识别与评论读取失败保留错误状态，并标明对应来源。

多来源资源页返回实际取得的来源页地址。想要卡片顶部按来源展示站名按钮，包含 favicon 与外链。已核对番号的 JavBus 作品页可以确认该页磁链的归属，种子名称的论坛前缀与尾标不再造成未命中。

已取得的正片磁链经现有想要查找结算入口记为 `found`。页面通过写接口同步结果，后台查找也先结算缓存中的既有命中。查询 GET 保持只读。

## 升级

旧版部分失败缓存保留磁链证据并标记过期，下一次查询重新取数。已有命中自动解除暂时放弃并清零未命中计数。接口恢复与来源错误均按当前请求表达。
